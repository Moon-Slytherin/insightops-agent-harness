# 产品说明

## 项目是什么

InsightOps Agent 是一个面向产品经理、用户运营和质量团队的产品事故调查助手。它从用户反馈中识别异常，通过只读 SQL 查询与产品文档检索收集证据，再输出可能原因、来源和不确定性。

## V1 演示故事

2026年8月3日发布 3.2.1 版本后，支付失败投诉从前一周 5 条增加到 18 条，其中 16 条来自 3.2.1。同日版本说明记录了 Android 支付 SDK 和失败重试配置变更。系统将其标记为优先排查线索，但明确说明仍需服务端日志确认因果。

## 当前已完成

- 45 条含异常、紧急项和重复项的模拟反馈；
- SQLite 自动初始化及只读查询保护；
- 支付失败趋势和版本分布统计；
- 本地产品文档检索及来源展示；
- 调查结论、置信度、限制和工具轨迹；
- 一次 SQL 超时重试演示；
- 对非支持问题拒绝猜测；
- 9 条自动测试和 12 条场景评测；
- 可直接打开的 Web 演示页面。

## 当前没有完成

- 大模型与 LangGraph；
- 向量数据库或混合 RAG；
- PostgreSQL、Docker与线上部署；
- CSV上传、自动分类和隐私脱敏；
- 真实企业数据与线上用户指标。

简历和面试中只能陈述“当前已完成”部分。未完成部分属于后续路线，不提前包装为成果。
