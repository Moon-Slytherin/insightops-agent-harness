# 48小时投递前冲刺

## 第1天：运行和理解（2小时）

1. 按 README 创建环境并启动程序；
2. 打开首页，点击“开始调查”；
3. 勾选超时选项，再调查一次；
4. 打开 `/docs`，观察三个核心接口；
5. 阅读 `main.py`、`agent.py` 和 `analytics.py`；
6. 能用自己的话解释：问题怎样进入、查了什么、证据从哪里来。

完成标准：能够不看稿演示一次完整调查。

## 第2天：测试和求职表达（2小时）

1. 运行 `pytest` 并看到 9 条通过；
2. 打开 `/api/evals`，找到唯一失败案例；
3. 阅读 `docs/INTERVIEW_GUIDE.md`；
4. 录制一次 60～90 秒本地演示；
5. 把真实项目描述加入简历；
6. 创建 GitHub 仓库并上传代码。

完成标准：简历、仓库和演示材料可以用于9月初投递。
