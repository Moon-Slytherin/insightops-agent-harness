# 第1天｜两小时运行与理解

今天不要求独立重写代码。目标是把已经完成的 V1 在你的电脑上运行起来，并能解释主流程。

| 时间 | 任务 | 完成标志 |
|---|---|---|
| 0～25分钟 | 创建虚拟环境、安装依赖 | 命令没有报错 |
| 25～45分钟 | 启动服务并打开首页 | 看见四个指标卡片 |
| 45～65分钟 | 运行普通调查和超时调查 | 看见证据与重试轨迹 |
| 65～75分钟 | 休息 | 离开屏幕 |
| 75～100分钟 | 阅读 `main.py`、`agent.py` | 能说清入口和工作流 |
| 100～115分钟 | 运行 `pytest` | 看见9条通过 |
| 115～120分钟 | 记录问题 | 写下一个不懂的点 |

今天合格标准：能够用30秒说明“问题进入 FastAPI 后，工作流调用 SQL 和知识检索，再把证据组织成结论”。
